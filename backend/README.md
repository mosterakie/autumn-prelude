# 后端与 Agent

此目录用于同一个 FastAPI 后端项目中的业务、Agent 和后台作业。当前尚未创建可运行应用或安装依赖。

## 计划模块

- api：身份、内容、知识库、对话、任务和设置接口。
- auth：邮箱加密码、验证、管理员额外验证和权限上下文。
- services：文章、收藏、公开范围、保存策略及账号额度。
- agent：角色、工作流、工具白名单、记忆与运行状态。
- ingestion：公开网页抓取、文本型 PDF 与 DOCX 解析和索引。
- jobs：后台处理、重试和取消；期限清理默认不启用。
- storage：数据库访问、文件存储和对象依赖。

Agent 工具和普通 API 调用同一套业务服务。统一 /api/ask 入口从服务端身份决定资料与工具范围。

## 服务选择

DeepSeek 用于主对话与工具调用，Tavily 用于站长联网搜索。百炼建议用于向量化，重排序按需要启用；具体模型 ID、接入地域及百炼职责后续配置。

初期建议 PostgreSQL 加 pgvector。模型与存储实现均保留适配层，密钥只通过后端环境配置传入。

## 必须满足的行为

- 普通用户验证邮箱后冷却 24 小时，之后每日 10 次 AI 请求，参数可调整。
- 普通用户不能调用联网搜索和网页抓取工具。
- 动态收回公开权限时同步检索、缓存和后续上下文，防止继续引用旧资料。
- 文章、收藏、聊天和日志默认永久保留，仍支持主动删除及后续期限配置。
- 重复请求和工具重试不能导致重复收藏、发布或计数。
- 不支持扫描件 OCR 和旧版 DOC；不支持登录后才可读取的第三方网页。
