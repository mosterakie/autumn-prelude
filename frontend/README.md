# 前端

此目录用于秋序的独立前端应用，当前尚未初始化框架或安装依赖。Next.js 与 TypeScript 是现阶段建议。

## 页面与交互

- 公开首页、手记、收藏、关于和留言列表。
- 邮箱注册、验证、邮箱加密码登录与找回密码。
- AI 对话、来源引用、额度提示和个人会话历史。
- 站长工作台、资料处理状态、操作预览及管理表单。
- 首页常规立绘与对话区域像素角色；角色状态由真实任务事件驱动。

公开页面不强制登录。需要鉴权的操作触发登录流程，并在完成后回到原位置。

前端只通过后端 API 操作数据，不持有模型服务密钥，不以客户端角色字段决定权限。前后端独立运行，业务与 Agent 统一由 backend 承担。

产品名称使用“秋序 / Autumn Prelude”；设计参考图中的“青序”是历史占位名。
