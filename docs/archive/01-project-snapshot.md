## 目前能使用什么

真实 API 模式下，已有账号认证、公开读取、留言审核、手记/收藏原稿 CRUD、发布预览与确认、私人/公开资料模式聊天、任务恢复、来源展示和额度管理基础能力。API 和 Worker 必须同时运行，且对应供应商与检查点已配置，才能处理模型和邮件任务。

Agent 当前注册五种工具：`search_knowledge`、`search_web`、`propose_bookmark`、`propose_note`、`propose_action`。服务端按当前身份和会话裁剪；创建与管理工具生成具体预览，由用户在界面确认后执行。保存收藏 URL 本身不要求联网抓取。

“公开模式会话”描述可检索的资料范围，聊天仍只属于当前账号，不会因此公开聊天记录。站长也没有读取他人聊天的权限。

## 仍有明显缺口

| 范围                 | 已有部分                               | 待完成部分                                                          |
| -------------------- | -------------------------------------- | ------------------------------------------------------------------- |
| 知识库文件/网页导入  | 解析、存储、索引 Service 和 Worker     | 前端使用的 `/knowledge/files`、`/knowledge/urls` 尚无注册 HTTP 路由 |
| 任务卡片             | 后端 owner jobs 列表与验证恢复         | 前端通用 `/jobs/{id}` 查询/取消/重试没有对应路由                    |
| 设置/记忆/审计工作台 | 数据表、部分 Service、确认动作 handler | `/settings/*`、`/memories`、`/audit-events` 管理 HTTP 接口与联调    |
| 保留策略             | forever 默认、策略表和预留动作词表     | TTL 预览、生效范围、历史清理及完整操作流程                          |
| 邮件                 | SMTP 适配、模板和任务结算              | 站长填写授权码后的真实登录、投递及浏览器验证/重置流程               |
| 自动摘要/记忆召回    | 存储实体和来源依赖检查                 | 默认 Agent 尚未自动生成摘要或选择记忆；不自动生成用户画像           |
| 重排序               | 可选端口和调用账本                     | 具体真实 rerank 供应商接入与验收未交付                              |
| SSE                  | 持久事件、累计快照和重连               | 当前模型驱动没有供应商逐 token 流式输出                             |
| 生产运行             | 本地配置和开发运行说明                 | HTTPS、域名、备份恢复、生产角色、监控及上线验收                     |

前端 demo 的知识队列和设置交互只是内存模拟。切换真实 API 后缺口应显示实际错误，不能通过演示结果宣布已完成。
