## 当前建议

- 同仓管理 frontend 与 backend。
- 前端使用 Next.js 与 TypeScript。
- DeepSeek 负责对话和任务理解；Tavily 负责搜索及可选正文提取；百炼负责向量化与可选重排序。
- 每日额度按 Asia/Shanghai 自然日零点重置。
- 每分钟最多 3 次、最多 1 个并发 AI 任务。
- 管理员使用独立角色与额外验证。
- 新建内容默认私密，公开字段明确设置。

以上建议不代表具体服务型号、预算或验证方式已最终确定。
