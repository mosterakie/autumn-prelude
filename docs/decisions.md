## 本轮工程设计基线

- 同仓管理 frontend 与 backend。
- 前端使用 Next.js App Router、TypeScript 与 Tailwind CSS。
- DeepSeek 负责对话和任务理解；Tavily 负责搜索及可选正文提取；百炼负责向量化与可选重排序。
- 每日额度按 Asia/Shanghai 自然日零点重置。
- 普通用户每个固定 60 秒窗口最多受理 3 次、最多 1 个并发 AI 任务，均可配置。
- 管理员使用独立角色与 TOTP 额外验证，默认有效 15 分钟。
- 新建内容默认私密，公开字段明确设置。
- 服务端会话配合 HttpOnly Cookie；已认证写请求校验 CSRF。
- 内容原稿和公开版本分别保存，公开检索只索引公开投影。
- PostgreSQL 持久作业队列，同后端项目启动 worker，首版不强制 Redis。
- 问答先创建 run 再通过 SSE 累计消息快照更新，重连不重复扣次。
- SQLAlchemy 与 Alembic 管理业务模型和迁移；数据库设计向量列暂按 1024 维。

以上为进入实现的工程基线，具体模型 ID、接入地域和调用预算仍通过配置确定。详细定义以[技术设计总览](architecture/README.md)及其接口与数据库文档为准。
