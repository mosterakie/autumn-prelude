# 秋序前端设计

版本：v1.0。接口字段和事件参见[接口契约](api-contract.md)。

## 技术与职责

采用 Next.js App Router、TypeScript 和 Tailwind CSS。内容页面优先服务端渲染以便阅读和分享；聊天、表单、上传与像素角色作为交互组件。Next.js 支持服务端与客户端组件的组合，适合这种页面分工。[Next.js 官方说明](https://nextjs.org/docs/app/getting-started/server-and-client-components)

FastAPI 是唯一业务后端。前端不直连数据库或模型服务；Next.js 的 /api 转发只处理传输，不签发第二套登录身份。首版不使用 Next.js Server Actions 执行业务修改。

服务端状态采用 TanStack Query，缓存仅留在内存；表单草稿与界面状态由组件管理。跨页面共享的会话信息来自 /api/auth/me。退出时清空个人缓存、关闭事件流，跨标签页通过 BroadcastChannel 同步退出事件。

## 路由与权限

| 页面路径 | 可访问身份 | 页面职责 |
| --- | --- | --- |
| / | 所有人 | 秋序首页、最新文章、精选收藏、助手入口 |
| /notes 与 /notes/[slug] | 所有人 | 公开文章列表与详情 |
| /bookmarks | 所有人 | 公开收藏字段与站长允许公开的备注 |
| /guestbook | 所有人浏览，登录后提交 | 已审核留言、回复、举报 |
| /about | 所有人 | 简介与外部账号 |
| /login 与 /register | 所有人 | 邮箱加密码登录、注册 |
| /verify-email 与 /reset-password | 持一次性凭据者 | 验证邮箱、重设密码 |
| /chat 与 /chat/[id] | 已验证且已登录者 | 普通用户 AI、本人公开资料模式会话 |
| /account | 本人 | 账号、会话、额度与退出 |
| /admin/chat 与 /admin/chat/[id] | 站长额外验证有效 | 私人助手，不能与普通模式混用上下文 |
| /admin/content | 站长额外验证有效 | 文章和收藏、版本及公开设置 |
| /admin/knowledge | 站长额外验证有效 | 文件、网页、处理状态和引用检查 |
| /admin/moderation | 站长额外验证有效 | 留言审核、举报处理 |
| /admin/settings | 站长额外验证有效 | 额度、保存策略、角色配置与审计入口 |

这些路由只是界面入口；后端对每个接口独立鉴权。私密或不存在的公共文章均展示 404。普通用户访问管理页显示无权限，不渲染管理数据。

首页打开无需登录。未登录点击“发送”“写留言”时再触发登录；只允许站内相对路径作为返回地址，避免任意外跳。登录后返回原页并恢复尚未发送的本地内存草稿。

## 用户可见状态

| 状态 | 界面行为 |
| --- | --- |
| 未登录 | 可阅读公开内容；鉴权操作显示登录入口 |
| 已登录但邮箱未验证 | 显示验证提示和重新发送；不能提交留言或问答 |
| AI 冷却中 | 显示 cooldown_until；留言仍可提交并审核 |
| AI 额度已用完 | 显示剩余 0 与 next_reset_at；保留已输入问题 |
| 普通可用 | 显示每日额度，可使用站内问答，无联网按钮 |
| 站长已登录未额外验证 | 仅公开模式；进入管理或私人会话时要求额外验证 |
| 站长验证有效 | 管理与私人助手可用 |
| 验证中途过期 | 暂停管理动作；重新验证后恢复明确的待执行操作 |
| 账号禁用或登录失效 | 关闭事件流、清除敏感视图，保留可公开浏览部分 |

倒计时以服务端 server_time 和截止时间计算，不能以设备时间决定是否获准调用。发送前不只依赖页面中的剩余次数，始终接受后端返回的判定。

## 页面组件

公共部分包含 SiteHeader、Hero、NoteList、BookmarkList、Guestbook、Footer。用户部分包含 AuthDialog、ChatSidebar、MessageList、Composer、CitationDrawer、QuotaHint。站长部分包含 ResourceEditor、PublicationPreview、KnowledgeQueue、ActionPreview、RetentionEditor。

像素角色由 AssistantAvatar 单独管理，不把模型提示词、角色名和业务权限写进角色组件。主题包含配色、圆角、常规立绘与像素资源路径；当前保留阮梅和停云对比方案，首页名称统一为“秋序 / Autumn Prelude”。

## 聊天交互

1. 首次发送前创建 conversation；mode 为 public 或 owner，创建后不能修改。
2. POST /api/ask 带 Idempotency-Key、conversation_id、client_message_id 和正文。
3. 收到 202 与 run_id 后，订阅 GET /api/runs/{run_id}/events。
4. 按 content_version 替换累计消息快照、展示引用与任务状态；保存最后一个事件序号。
5. 断线时使用同一个 run_id 和事件游标重连，不能重新创建 ask。
6. GET /api/runs/{run_id} 可恢复最新状态和最终消息；完成后再次读取额度。
7. “停止”发送取消请求，状态先变 cancelling，收到终态后才显示已停止。

“重试请求”复用原 Idempotency-Key；“重新生成回答”是新的请求，可能产生新的一次计数，两者按钮文案分开。每个会话同时只运行一个任务；站长可在不同会话中按自己的并发上限运行。

普通用户的回答可流式显示。引用资料一旦失去权限，服务端发 source.invalidated 或 scope.changed，前端隐藏受影响的生成内容并刷新会话。已经看到的文字不能撤销，但后续不能继续从缓存读取或送给模型。

### 角色状态映射

| 服务端或界面状态 | 像素表现 |
| --- | --- |
| 无任务 | 待机 |
| 输入框聚焦 | 倾听 |
| queued 或 running | 思考 |
| tool.started 或 knowledge.processing | 执行 |
| waiting_input、waiting_approval 或 waiting_auth | 需要处理 |
| succeeded | 完成后回到待机 |
| failed 或 cancelled | 简短提示后回到待机 |

开启“减少动画”时使用静态状态图。角色可收起，不遮挡正文、输入框和手机键盘，不自动播放声音。

## 站长内容操作

编辑表单和助手共用业务服务。普通草稿保存返回 ResourceDTO；需要预览或确认的发布、策略变更返回相同的 ActionDTO。存在明确、充分授权的低影响动作可直接执行；需要确认时展示对象、字段差异、目标版本和影响范围。

公开预览只展示拟公开字段。收藏标题、网址和备注分别选择；网页快照或 PDF 原件下载为独立选项。默认不勾选私人备注和原文件。提交携带 expected_version，内容已被另一操作修改则展示 409 VERSION_CONFLICT 并重新取数。

页面上的“保存草稿”“公开当前版本”“收回公开”是不同动作。修改公开文章的草稿不会自动更新正在展示的公开版本；可明确发布新版本。

## 知识库交互

提供“粘贴链接”和“上传文件”两个入口。链接区分仅收藏、正文入库、同时收藏并入库。文件接受文本型 PDF、DOCX；建议初始单文件上限 20 MiB，从后端配置读取。

上传完成不等于入库完成。依据 JobDTO.status 和 phase 展示排队、抓取、解析、向量化、完成、失败或取消；waiting_auth 显示重新验证入口。允许查看错误、取消和重试。扫描 PDF、DOC、登录墙分别显示可理解的提示，不能显示假成功。

PDF 来源显示页码；DOCX 显示章节或段落；网页显示标题、URL、抓取时间。打开受保护的原文件仍由后端检查权限，前端不保存长期公开下载地址。

## 数据缓存与内容呈现

首版所有权限相关 API 和资料详情采用 no-store，SSR 获取公开内容也不使用长时间页面缓存，以优先保证撤回生效。未来引入缓存必须带 publication_id、acl_version 并有可靠失效策略。

列表查询键包含 mode 与当前用户 ID；退出清空，不能在另一用户登录后复用。UI 乐观更新只用于可恢复的轻量体验，权限、发布和删除必须等待服务端成功。

文章和模型 Markdown 经过安全渲染，不执行原始 HTML、脚本或模型返回的事件属性。外链只允许 http/https，必要时标识站外链接。私密问题不会通过预取、分析埋点或前端报错日志上传给其他服务。

## 前端验收

- 手机、桌面、键盘操作和减少动画模式可用；正文与按钮满足可读对比度。
- 未登录可浏览；登录后返回原操作；冷却、额度与验证到期提示正确。
- 切换账号不残留旧聊天、文件或角色气泡。
- SSE 断线重连无重复消息、重复工具卡片和重复扣次。
- 文章公开版本与私密草稿可独立编辑；撤回后刷新与后退不再读出旧缓存。
- UI 在后端确认成功后报告修改结果；异步操作等待 action.succeeded，后端失败时保留可重试状态。
